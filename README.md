# BHAMA Shopify Theme

Ready-to-upload Shopify Online Store 2.0 theme for BHAMA.

Includes:

- Modern BHAMA home page
- Sticky-gallery single product page
- Add to Cart and Buy Now buttons
- BHAMA collection grid
- Local product images and reel-style video assets
- Demo Shopify product import CSV

Shopify Theme Check passes with zero offenses.

## Demo Products

Import `demo-products.csv` in Shopify Admin:

1. Go to Products.
2. Click Import.
3. Upload `demo-products.csv`.
4. Enable image download/import when Shopify asks.

The file contains 10 demo products and 25 variants using BHAMA saree, suit set, kurthi, and co-ord catalog data.
